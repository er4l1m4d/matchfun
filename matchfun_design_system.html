Color

Every accent color in MatchFun has exactly one job. Orange means act — it's the only color on a primary button. Teal means live data — odds, scorelines, timestamps. Yellow means reward — streaks, NFTs, first place. If a color starts doing a second job, the system has broken down.

Typography

Inter carries every headline and UI label — clean, high x-height, reads fast at small sizes on a phone in a noisy stadium. Space Mono is reserved for anything that ticks: odds, scores, timers, wallet addresses. When a number is live, it's in mono. When it's prose, it's in Inter.

Motion

Fast and confident for anything the user directly touches; a single bounce reserved for moments worth celebrating. Hover this card.

ease-out · 120ms
taps, hovers
ease-in-out · 200ms
panels, tabs

Rule of one bounce: ease-bounce is reserved for genuine celebration moments — a correct streak, an NFT mint, a leaderboard climb. If every hover state bounces, none of them feel earned.

Guidance

Usage Guidelines

Four principles that decide most design questions before they become debates.

01
One job per color
Orange acts, teal reports, yellow rewards. If you're unsure which to use, ask what the element is doing — not what looks nice.
02
Dark is the brand
MatchFun reads like a stadium at night, not a spreadsheet in daylight. There is no light theme — see below.
03
Numbers are mono
Anything that ticks live — odds, scores, timers — sits in Space Mono with tabular numerals so it never reflows.
04
Earn the bounce
Ease-bounce motion is reserved for celebration. Everyday taps get a fast, quiet ease-out.
Why no light mode

MatchFun is built to be read one-handed, at a glance, often at night, often next to an actual TV broadcast. Sofascore, Flashscore, and DraftKings all default to dark for the same reason — high-contrast data on black is faster to parse under match-day conditions than dark text on white. A toggle would mean maintaining two brands; instead every token here is tuned for exactly one.

Component do's and don'ts
Do

Use the streak chip and gradient only when a real streak is active. It should mean something every time it appears.

Don't

Decorate unrelated UI with the streak gradient just because it looks energetic — it should stay tied to the streak mechanic.

Do

Lock prediction tiles the instant a play starts, with a visible locked state — never let a user tap after the window closes.

Don't

Rely on a disabled cursor alone to communicate "locked" — pair it with reduced opacity and the lock state styling.

Guidance

Accessibility

A dark, high-energy aesthetic still has to hold up under WCAG AA. Every text token below was picked against its intended background.

Contrast reference
18.5:1
text-primary on bg-void
9.1:1
text-secondary on bg-surface
6.4:1
text-on-color on orange-500
11.8:1
teal-300 on bg-surface
5.0:1
text-tertiary on bg-surface

All ratios measured against WCAG 2.1 — every pair above clears 4.5:1, the AA threshold for body text. text-tertiary is the tightest in the system, which is why it's reserved for captions and hints rather than primary content.

Never color alone
Correct/incorrect prediction tiles pair color with an icon and a state class — colorblind users get the same information through shape, not just hue.
Visible focus ring
Every interactive element gets a 2px teal outline on keyboard focus — :focus-visible, never suppressed.
Reduced motion respected
Confetti, streak bounces, and scroll reveals all collapse to near-instant under prefers-reduced-motion.
Tap targets ≥ 44px
Prediction tiles, bottom nav items, and icon buttons all hold a minimum 44×44px hit area even when the visual icon is smaller.
ARIA labels on icon-only controls
Every icon button ships an aria-label — "Notifications," "Close," "Share" — never a bare glyph for screen readers.
Guidance

Voice & Tone

MatchFun talks like a sharp mate who's watching the same match as you — short, confident, a little cheeky when you're winning, never patronizing when you're not.

"Locked in. Odds were 2.5 — nice pick."
"Your prediction submission has been successfully processed."
"Missed that one. Dembélé's still up next."
"Unfortunately, your prediction was incorrect. Better luck next time!"
"Nothing live right now — set a reminder for kickoff."
"No data available. Please check back later."
"5 in a row. That's a Hot Streak — claim it."
"Congratulations! You have achieved a milestone."
Buttons keep their name: a button that says "Claim NFT" produces a toast that says "NFT claimed" — never "Success!" The vocabulary of an action stays identical from tap to confirmation.

Brand Assets

The mark is a ball mid-motion inside a floodlit gradient tile — it should always sit on dark or on the hero gradient itself, never on a plain white card.

Do

Keep at least 16px of clear space around the mark on every side — it needs room to read as a floodlit tile, not a busy icon.

Don't

Place the mark on white, on photography, or recolor the gradient tile — it's calibrated for the night-pitch palette only.

Icon system

Single stroke-based sprite, 1.75px stroke weight, 24×24 viewBox, rounded caps and joins. Icons inherit currentColor — never hard-code a fill.

Illustration style

Flat gradient fields (hero, streak, or NFT gradients) with a single line-art motif — never full-color illustration or stock photography. Used behind empty states, achievement cards, and NFT placeholders.
